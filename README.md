# CloudPortfolio — Cloud Computing Mini Project

**Developed by:** Priyanka Bhujbal

## About the Project
CloudPortfolio is a responsive student portfolio website created using HTML, CSS, and JavaScript. It introduces cloud computing concepts, including cloud storage, Content Delivery Networks (CDNs), and HTTPS.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub and GitHub Pages (for source-code hosting and website deployment)

## Features
- Responsive portfolio layout
- Cloud computing information cards
- Interactive greeting button
- Student project details

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project Status
The portfolio website is designed for a Cloud Computing mini project. Any cloud storage integration or CDN configuration will be documented separately once implemented and tested.
